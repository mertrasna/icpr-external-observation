# Local generated output

This directory is an ignored workspace for tables and figures produced while a
researcher exercises the methods. The public repository contains these guides,
not study findings or generated artifacts.

`make demo-egress` and `make analyze-egress` write beneath
`results/egress-catalogue/generated/` by default. Files there are disposable
outputs and must not be mistaken for source inputs or bundled reference results.

If outputs are later shared, release them separately with their input manifest,
source revision, dependency versions, exact command, and appropriate privacy,
licence, and provenance review.
